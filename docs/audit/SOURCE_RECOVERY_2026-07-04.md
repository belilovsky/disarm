## Что делать, когда появится owner decision по VCS

1. Найти старый private repo или подтвердить, что его больше нет.
2. Если старый repo найден:
   - клонировать его отдельно;
   - сравнить file inventory и SHA по критическим публичным файлам;
   - перенести only verified production state поверх canonical repo.
3. Если старый repo не найден:
   - завести новый canonical repo как отдельное осознанное действие;
   - стартовым содержимым брать текущее локальное дерево плюс этот recovery note;
   - отдельно зафиксировать, что история до 2026-07-04 отсутствует и заменяется snapshot/backups.
