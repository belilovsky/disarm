# DISARM design pass — blue matrix — 2026-06-11

## Цель

Сделать вкладку `Матрица защиты` удобнее для ежедневной работы с большим списком контрмер: быстрее понимать масштаб тактики, лучше сканировать длинные названия и не терять связи с техниками.

## Что изменено

- Заголовок вкладки переведён в плотную рабочую сетку: текст слева, фильтры справа.
- Панель фильтров получила AV DS-поверхность, как на `red`, чтобы поиск и фазы воспринимались единым toolbar.
- В заголовки колонок добавлены счётчики контрмер, например `28 контр.`.
- Количество связанных техник в карточках контрмер оформлено как компактный синий бейдж.
- Desktop сохраняет намеренный горизонтальный matrix-scroll с читаемой шириной колонок.
- Mobile остаётся в accordion-режиме без горизонтального overflow.
