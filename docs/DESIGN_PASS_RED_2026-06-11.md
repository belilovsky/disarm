# DISARM design pass — red matrix — 2026-06-11

> Исторический срез. Текущее состояние DISARM 1.7 описано в docs/PREPRODUCTION_1_7.md; старые версии и незакрытые на дату отчёта задачи не являются текущим статусом.


## Цель

Сделать вкладку `Матрица атак` удобнее как рабочую поверхность: меньше пустого вступительного пространства, понятнее панель фильтров, читаемее колонки техник, без пустого блока легенды.

## Что изменено

- Заголовок вкладки переведён в плотную рабочую сетку: краткое описание слева, controls справа.
- Панель фильтров получила отдельную поверхность AV DS: поиск, фазы, тепловая карта и экспорт теперь читаются как единый toolbar.
- Колонки матрицы стали шире на desktop (`~230px`), поэтому названия техник меньше ломаются.
- Матрица получила `width: max-content` только на desktop/tablet, чтобы горизонтальный скролл был намеренным, а не случайным сжатием.
- На mobile матрица возвращается в accordion-режим без горизонтального overflow.
- Исправлен визуальный баг: скрытая легенда `#red-legend` больше не рисуется пустой полосой.
- Проверено включение тепловой карты: legend появляется, все 71 техники получают heat-state.
