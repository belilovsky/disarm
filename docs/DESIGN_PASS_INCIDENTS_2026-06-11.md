# DISARM — дизайн-проход Incidents, 2026-06-11

## Цель

Сделать каталог инцидентов более пригодным для ежедневного просмотра: уменьшить высоту фильтров, поднять список карточек выше и добавить понятный статус выдачи.

## Что было не так

- На мобильной ширине фильтры занимали слишком много места: блок пилюль был около `512px`, а список карточек начинался ниже `1200px`.
- На desktop длинная группа тактик растягивала фильтры и отодвигала карточки вниз.
- После поиска или выбора фильтра не было явного статуса, сколько инцидентов показано.

## Что изменено

- Фильтры сгруппированы по смыслу: год, страна, тактика.
- Desktop-панель фильтров ограничена по высоте, длинные группы остаются доступными внутри панели.
- Mobile-фильтры стали горизонтальными рядами без вертикальной простыни.
- Добавлен статус `#incident-status`:
  - все инциденты;
  - количество после поиска;
  - активные фильтры.
- Empty-state каталога теперь объясняет, как вернуться к результатам.
- Cache-bust обновлён до `20260611-incidents1`.

## Проверка

- `node --check assets/app.js`
- локальный Playwright-smoke на `http://127.0.0.1:4187/?tab=incidents&v=incidents-after2`
- проверены ширины:
  - `1440x1000`
  - `390x900`
- проверены сценарии:
  - общий список: `63` инцидента;
  - поиск `USA`: `14` инцидентов;
  - сброс фильтров;
  - открытие модальной карточки;
  - отсутствие горизонтального скролла.

## Метрики

- Desktop: высота панели фильтров `270px` → `136px`.
- Mobile: высота панели фильтров `512px` → `229px`.

## Риск

Низкий. Изменения ограничены вкладкой `incidents`; данные каталога не менялись.
