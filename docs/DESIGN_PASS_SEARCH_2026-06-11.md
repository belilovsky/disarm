# DISARM — дизайн-проход Search, 2026-06-11

## Цель

Сделать вкладку поиска пригодной для ежедневной работы: меньше высота первого блока, быстрее доступ к выдаче, понятный статус результатов и аккуратные состояния без выдачи.

## Что было не так

- На мобильной ширине блок поиска занимал почти весь первый экран: поле, фильтры, подсказка и популярные запросы складывались в высокую карточку.
- Результаты оказывались слишком низко, хотя поиск является рабочим инструментом, а не промо-разделом.
- Empty-state был слишком нейтральным и не объяснял, что делать дальше.
- Пользователь не видел, сколько объектов найдено и сколько показано после применения фильтров.

## Что изменено

- Блок `.avds-search-hero` переведён в компактную рабочую карточку AV DS 4.
- На мобильной ширине фильтры и популярные запросы стали горизонтальными рельсами без роста высоты.
- Добавлен живой статус `#search-status`:
  - пустой запрос;
  - ничего не найдено;
  - найдено / показано / число активных фильтров.
- Empty-state оформлен как спокойный рабочий блок, без курсивного “заглушечного” вида.
- Cache-bust обновлён до `20260611-search1`.

## Проверка

- `node --check assets/app.js`
- локальный Playwright-smoke на `http://127.0.0.1:4187/?tab=search&v=search-after`
- проверены ширины:
  - `1440x1000`
  - `390x900`
- проверены сценарии:
  - пустой поиск;
  - запрос `T0049`;
  - счётчик результатов;
  - отсутствие горизонтального скролла;
  - открытие модальной карточки из результата.

## Риск

Низкий. Изменения ограничены вкладкой поиска, общими данными и матрицами не управляют.
